# 25 ALGORITHMS

### Sorting Algorithms (~5-6)

- Bubble Sort (for learning, rarely used in practice)
- Merge Sort
- Quick Sort
- Heap Sort
- Insertion Sort
- Counting/Radix Sort (for special cases)

### Searching Algorithms (~3-4)

- Linear Search
- Binary Search
- Depth-First Search (DFS)
- Breadth-First Search (BFS)

### Graph Algorithms (~5-6)

- Dijkstra's Algorithm (shortest path)
- Bellman-Ford (shortest path with negative weights)
- Kruskal's / Prim's (minimum spanning tree)
- Topological Sort
- Union-Find (Disjoint Set)

### Dynamic Programming Patterns (~5-6 core patterns)

- Fibonacci-style memoization
- Knapsack problem
- Longest Common Subsequence
- Longest Increasing Subsequence
- Edit Distance

### Other Fundamentals

- Recursion & Backtracking
- Two Pointers / Sliding Window
- Hashing
- Greedy Algorithms
- Bit Manipulation basic
